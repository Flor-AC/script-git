# Scripts Git - Guía Completa

Este repositorio contiene **una guía práctica de comandos Git**, diseñada tanto para **uso personal** como para **enseñanza a alumnos**. Aquí encontrarás desde la inicialización de un repositorio hasta flujos colaborativos y manejo de conflictos, con ejemplos claros y fáciles de seguir.

## Contenido

| Archivo | Descripción |
|---------|-------------|
| `01-inicializar-repo.md` | Cómo crear un repositorio local y configurar Git por primera vez. |
| `02-agregar-archivos.md` | Agregar archivos al staging y preparar commits. |
| `03-commits.md` | Cómo realizar commits, ver el historial y modificar commits recientes. |
| `04-ramas-branches.md` | Creación y manejo de ramas, y cómo hacer merge. |
| `05-pull-push.md` | Subir y bajar cambios desde el repositorio remoto en GitHub. |
| `06-flujo-colaborativo.md` | Flujo de trabajo colaborativo con forks, pull requests y resolución de conflictos. |
